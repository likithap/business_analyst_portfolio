# ✈️ British Airways Review Dashboard
This Tableau dashboard provides a comprehensive analysis of passenger reviews for British Airways flights. It enables interactive exploration of various performance metrics and trends based on aircraft type, 
seat type, continent, and traveler demographics.

View the interactive dashboard here: 

👉 [View on Tableau] (https://public.tableau.com/views/BritishAirwaysReview_17440686522400/Dashboard1?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

## 📊 Key Features:
- **Review Volume Analysis**
View the number of reviews by aircraft type to understand customer engagement.

- **Metric Comparison**
Compare average ratings of different service areas such as:
  - Cabin Staff Service
  - Seat Comfort
  - Ground Service
  - Value for Money
    
- **Filter reviews by:**
  - Aircraft group
  - Seat type
  - Traveler type
  - Continent
  - Month of travel

- **Dynamic Metric Selector**
Choose the service metric to analyze and visualize trends interactively.

- **🛠️ Tools Used:**
  - Tableau Public for data visualization
  - CSV Dataset containing British Airways review records

- **📁 Dataset Includes:**
  - Aircraft type
  - Review date and rating
  - Traveler type and class
  - Multiple service metrics (Cabin Crew, Food, Entertainment, etc.)
